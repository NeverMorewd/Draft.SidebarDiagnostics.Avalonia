# Modification Notice

Sidebar Diagnostics Avalonia is a modified version of Sidebar Diagnostics by ArcadeRenegade and its contributors:

https://github.com/ArcadeRenegade/SidebarDiagnostics

The cross-platform port began on August 28, 2026. It replaces the original Windows Presentation Foundation user interface and Windows-specific application architecture with Avalonia and platform-specific metric providers for Windows, macOS, and Linux. The port also introduces a new visual design, settings and startup services, automated tests, and multi-platform release automation.
